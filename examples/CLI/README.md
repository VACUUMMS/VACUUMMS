# Command Line Interface Examples

The polystyrene example requires a fair amount of pre-processing to put the original data file in the needed format, and that is what the majority of those scripts are for. 

The starting point for analysis is a collection of records in the GFG format, which is tab-separated values of x, y, z, sigma, and epsilon, plus metadata for the records, most importantly the three simulation box dimensions in x, y, z directions.
